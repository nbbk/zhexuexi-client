> 阶段 1 目标（DEV-PLAN §4.3）：接真实面板与节点、首页大开关可用、节点列表与流量到期显示。

## 已定约束（不重复写进每片）

- 订阅拉取每次显式带 `?format=singbox`，UA `Zhexuexi/0.1.0`；失败回退 base64 → clash（见 docs/api/panel-adapter.md §7）。
- 令牌只存系统密钥库，绝不写明文文件、不进日志、不进诊断包；订阅地址（不含令牌）存 shared_preferences。
- 解析订阅只取节点模型；`dns` / `route` / `proxy-groups` / `rules` 一律不透传，DNS 与路由由客户端自己生成（切片 2）。
- 面板 1.3.37 起 sing-box JSON 的 DNS 已是新格式（type/server/server_port，route 带 default_domain_resolver）；客户端仍按 §2.2 自己生成 DNS，不透传面板 DNS 段。
- 真面板联调、真机、APK、Win 构建每片都列为未测项，不在本机冒充已验。
